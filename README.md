# Escape Tsunami Brainrots Online

A minimal GitHub Pages page that embeds the original hosted game at:

https://gamea.azgame.io/escape-tsunami-brainrots-online/

The game fills the browser window. Use the game's own controls and progression system.

## Hosting

Publish the `main` branch root with GitHub Pages. No build or installation is required.

## External dependencies

This repository contains the embedding page, not the game's Unity source or a standalone copy of its game assets. The game loads from its original host and requires network access to that host and its dependencies. Availability and any hosting restrictions are controlled by the game provider. This repository does not claim ownership of the original game.
