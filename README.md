# Escape Tsunami Brainrots Online

A minimal GitHub Pages page that embeds the original hosted game at:

https://1games.io/game/escape-tsunami-brainrots-online/

The game fills the browser window. Use the game's own controls and progression system.

## Hosting

Publish the `main` branch root with GitHub Pages. No build or installation is required.

## External dependencies

This repository contains the embedding page, not the game's Unity source or a standalone copy of its game assets. The original game is distributed through 1Games; its main build files load from `play.1games.io`, and its SDK loads from `games.1games.io`. The browser also needs access to the provider's other dependencies. Availability and hosting restrictions are controlled by the game provider. Access on a particular school or other managed network has not been verified. This repository does not claim ownership of the original game.
